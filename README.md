# Solu-ao_Mudancas_Climaticas-
O projeto consiste em um site integrado com IA que pede para o usuário escolher um país do mapa que aparece na tela. Com o país escolhido a IA mostrará os problemas das mudanças climáticas na região, principais causas e o que é afetado. (pode ter voz para maior acessibilidade e tradução de noticias do próprio país)
